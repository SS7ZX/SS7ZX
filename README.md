I sit at the intersection of **Full-Stack Engineering**, **Offensive Security**, and **Product Design** — I don't just build applications, I stress-test them the way an attacker would, then close the gaps.

- 🎓 Undergraduate, **Information Systems Technology** (3rd Semester)
- 🥇 **BNSP-Certified Network Engineer** — Rank 1 nationally in Computer & Network Engineering (TKJ)
- 🏆 Recognized by **Universitas Siber Indonesia** for VAPT (Vulnerability Assessment & Penetration Testing) excellence
- 🧠 Solo-built **C-Pay**, a closed-loop campus payment system, end-to-end (schema → API → UI)
- 🐹 Currently deepening **Go (Golang)** for building fast recon/automation tooling
- 🟣 Aesthetic obsession: neon-purple, glitch, cyberpunk — because security work should look as sharp as it is
